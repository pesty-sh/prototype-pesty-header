Mouse, motion, and the wordmark.

The letters are a bitmap in a Rust field. Move and nearby speckles slide toward the cursor, then back out as it moves away. Hold, and an icon charges. A ball of pixels wanders on its own and fires one trail every few seconds.

  • Move slides speckles in toward the cursor
  • Move away and those speckles slide back out
  • Hold charges an icon
  • Release lets that icon run
  • The word plays the next appear
  • The drift fires one trail, then a burst

Scope

Three jobs, one buffer.

Pointer, motion, and the logo share a single RGBA buffer. The speckled ground is not a fourth job. The cursor can hoover it, and the wander can fire into it.

01

Pointer

Where the cursor sits, and how long the press has been held. Inside a wide radius a speckle slides toward the cursor as it approaches, and slides back out as the cursor moves away. The bar and the sentence are quiet rectangles, so the type stays put.

02

Motion

The mark prints from the left on the first load. Each click runs the next appear. A ball of pixels wanders the field. Every few seconds it fires one trail of pixels. The trail lands at a random point inside the canvas and bursts into a random icon. A release on the field still drops one icon of its own: it may appear, slide, or expand. Reduced motion holds the mark finished, skips the wander, and drops no icons.

03

Logo

The word is a bitmap, crest on the ascenders and dim on the tails. The demo redraws that bitmap from a title, a face, and two hex colours. The page uses the background hex while the wasm file is still loading.

Setup

Install

Node 20 or newer, and Rust with the browser target. Once per machine. 

node --version
npm --version
rustc --version
rustup target add wasm32-unknown-unknown

If node or npm is missing, install Node from nodejs.org and open a new terminal. If rustc is missing, install Rust from rustup.rs and open a new terminal. The wasm32-unknown-unknown target is what the page build uses.

First run

Getting started

From this folder. Leave the last command running, then open the page.

npm install
npm test
npm run dev
  1. npm install downloads the JavaScript packages. node_modules/ is not committed.
  2. npm test runs the Rust tests, builds public/engine.wasm, and checks that file. The last line should contain pesty engine ok.
  3. npm run dev builds the wasm again and serves the page.

Open 127.0.0.1:43123. You should see the word pesty.sh in pale pixels, a speckled field, and live at the top right. The port stays 43123 unless you set PESTY_PORT for one command.

Move across the header. Speckles inside a wide radius slide toward the cursor, and slide back out as the cursor moves away. Hold on the field, then release, and an icon runs. Click the word and the next appear plays: print, drop, rise, bloom, spark, then print again. A ball of pixels wanders on its own. Every few seconds it fires one trail. That trail lands inside the canvas and bursts into a random icon.

On this dev server the boxes under the sentence are live. Title is the string drawn in the field. Face is Pesty, Plex Mono, Georgia, or Impact. Tint and Background are hex colours. ?demo=0 is the public page, with those boxes gone. A published site opens them with ?demo. A shared link can carry the strings: ?demo&text=hello&face=georgia&tint=ff6040&bg=ffffff. The page paints that background while the wasm file is still loading.

If the browser asks for reduced motion, the letters are already finished, the wander does not fire, and a release drops no icon. The pointer still lights the cells under it.

Press Ctrl+C once in the dev terminal and wait until it prints Port 43123 is free. If that terminal is already gone, npm run stop frees a Vite process, or scripts/dev.mjs, whose working directory is this folder. A different program on 43123 is left running.

Knobs

Config

Picture settings live in engine/src/config.rs. Edit that file, run npm run build:wasm, and reload. The page does not read the file on its own.

Wander

DRIFT_FIRE turns the trail on. The ball of pixels stays either way. DRIFT_GAP_MIN_MS and DRIFT_GAP_MAX_MS are the wait, five to eight seconds. TRAIL_DOTS and TRAIL_SPREAD shape the shot. POP_EDGE keeps the burst inside the canvas.

Noise

NOISE_WELL_CELLS is how far a speckle will slide, in letter-cells. NOISE_WELL_PULL is how far it travels toward the cursor. NOISE_WELL_MASS is how bright the clump can get. The points keep their own places. NOISE_DENSITY is how many speckles the field keeps.

Pointer and icons

POINTER_FOLLOW is how fast the glow catches the cursor. CAST_RANDOM rolls the icon and the play. SLIDE_HOPS and SLIDE_SPIT belong to a travelling click. MAX_SPRITES caps clicks and fired trails together.

Page

How often the page draws, and the pixel-ratio cap, are FRAME_MS and DPR_CAP at the top of src/main.ts. Colours are the six values in engine/src/palette.rs, repeated as --bg, --lit, --mid, and --crest in src/style.css. Letter shapes stay in engine/mark.py.
